Stage 1 — Site vitrine entreprise

Fonctionnalité clé : intégration d'un agenda Google Calendar connecté via API avec le téléphone du gérant. L'agenda est visible et modifiable uniquement par un utilisateur authentifié sur le site.

Contexte

Réalisation d'un site vitrine avec WordPress pour une petite entreprise, avec besoin de gestion d'agenda centralisé et synchronisé avec le smartphone du gérant.

Fonctionnalité principale

  • Connexion à l'API Google Calendar (OAuth 2.0) pour lier l'agenda du gérant.
  • Synchronisation bidirectionnelle des événements entre le téléphone et le site.
  • Affichage calendrier côté site (lecture) uniquement si l'utilisateur est connecté.
  • Création / modification / suppression d'événements réservées aux comptes autorisés.

Accès et sécurité

  • Authentification obligatoire pour voir l'agenda (pas d'accès public).
  • Permissions fines: seuls les rôles autorisés peuvent modifier les événements.
  • Gestion sécurisée des jetons d'accès via le serveur.

Plateforme de communication

  • Il a été mis en place un Trello pour que le client puisse suivre l'avancement du projet.
  • Plusieurs réunions ont été organisées pour faire le point sur l'état d'avancement et la modification en amont.

Lien du Trello

Intégrations techniques

  • WordPress (thème léger + code personnalisé pour l'intégration API).
  • Extension "Google Calendar" par token avec une sécurisation par authentification.
